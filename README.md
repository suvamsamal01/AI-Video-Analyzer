🎬AI-Video-Analyzer
An advanced AI-powered desktop application that analyzes local videos and YouTube content, generates intelligent summaries, extracts key points, creates quizzes, detects chapters, and exports results to PDF.

Built with Python, PyQt5, Ollama, Faster-Whisper, and yt-dlp.

---

✨ Features

🎥 Video Analysis

- Analyze local video files
- Analyze YouTube videos
- Automatic speech transcription
- Video metadata extraction

🤖 AI-Powered Summaries

- Short Summary
- Detailed Summary
- Key Points Extraction
- Topic Detection
- Action Items Generation

📖 Smart Chapter Detection

- Automatic chapter generation
- Chapter summaries
- Timestamp organization
- Easy navigation

❓ Interactive Quiz Generator

- AI-generated MCQ questions
- Instant answer checking
- Quiz scoring system
- Explanation for answers

⏱️ Timestamp Extraction

- Important moments detection
- Quick content navigation
- Transcript segmentation

📄 Export Options

- Export summaries to TXT
- Export summaries to PDF
- Copy results to clipboard

🎨 Modern UI

- Dark theme interface
- Sidebar navigation
- Responsive design
- Progress tracking
- Drag & Drop support

📦 Installation

Clone Repository

git clone https://github.com/suvamsamal01/AI-Video-Summarizer-Pro.git
cd AI-Video-Analyzer

Install Dependencies

pip install -r requirements.txt

Install FFmpeg

Download and install FFmpeg:

https://ffmpeg.org/download.html

Run Application

python main.py
